Advanced Technologies Landing Page

The Advanced Technologies Landing Page is a responsive and visually appealing webpage built using HTML, CSS, and Bootstrap 4. The page presents a modern landing screen with a full-screen background image and an elegant information card positioned at the bottom.

The card introduces the concept of advanced technologies with a title, a short description, and two interactive buttons: Learn More and Save Draft. Bootstrap Flexbox utilities are used to align the content, while custom CSS provides styling for typography, colors, spacing, borders, and buttons.
